# Manuscript workspace instructions

These instructions apply to the entire `paper/manuscript/` subtree and extend
the workspace-level `AGENTS.md`.

Before editing manuscript prose, captions, generated inputs, references or the
Supplementary Information:

1. Read `agent.md` completely.
2. Read `state_machine.json` and work only on a TODO permitted by the current
   state, unless the user explicitly changes priorities.
3. Read the live claim and figure documents identified in `agent.md` for the
   section being edited.
4. Update `state_machine.json` after completing, blocking or deferring a task.

Do not read from, copy, modify or treat `../manuscript.tex` as a source for this
manuscript. It is a retired scaffold for this writing effort.

Do not edit `../figures/v1/*.pdf`, canonical `LOCKED` figure bundles, frozen
indexes, upstream runs or generated scientific tables by hand.

Use `references.bib` as a seed bibliography only. Verify relevance and metadata
before each citation, and add newly checked sources to the local file.

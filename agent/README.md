# Agent workflow records

These files document the constraints under which the analysis and manuscript
were prepared:

- `workspace_AGENTS.md` and `manuscript_AGENTS.md`: operational instructions;
- `writing_agent_contract.md`: manuscript structure and evidence-handling rules;
- `PAPER_ANALYSIS_AGENDA.md`: estimands and scientific stopping rules;
- `CLAIMS_EVIDENCE_MATRIX.md`: claim-to-artifact ledger;
- `FIGURE_PLAN.md`: figure contracts;
- `state_machine.json`: task-state snapshot at release preparation.

They are provenance records, not a standalone executable agent. No credentials,
chat transcripts, source imagery, or upstream run outputs are included.

## Scientific result

Newly observed buildings carry larger anchor-PV footprints per strict
first-appearance host and more PV area per corresponding risk unit, but this
advantage is outweighed by the much larger inherited-building exposure. The
result is a stock--flow decomposition, not a roof-utilization estimate, adoption
rate, installed-capacity measurement, forecast, or causal effect.

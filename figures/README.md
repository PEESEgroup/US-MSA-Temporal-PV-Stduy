Each of Figures 1--4 was copied from its approved, immutable manuscript bundle.
The original bundle README defines the estimand, exclusions, denominator and
rendering boundary. The included freeze manifests preserve the original
approval records; they may name authoritative files outside this curated
release.

The proprietary Arial font recorded by the original build is not included.
This release therefore uses its own top-level `release_manifest.json` for file
integrity. Do not interpret a missing-font entry in an original freeze manifest
as corruption of the curated release.

# Figure 3a appearance-sorted draft note

Cities are ordered from highest to lowest by the plotted PV first-appearance ratio. “PV first appearance” means the first accepted adjacent change from PV absent to PV present on a unique linked host; it is not an exact installation date. The pooled row remains last.

Each row compares newly observed buildings with existing-building observations using PV first appearances per building observation, PV area per building observation, and PV area per square metre of observed roof. For existing buildings, building and roof quantities are summed across eligible observed cohort transitions. Connected marks are alternative descriptions of one city, not a time trend or uncertainty interval. Only the final roof-area value is printed.
